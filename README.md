# Accordion — гармонический цвет (папка и бирка в workspace: `color_harmony`)

Некоммерческий фоторедактор для Apple-платформ, где цвет правится через отношения между цветами, а не через пресеты
и нейросетевые «чёрные ящики». Нейтрали — жёсткие опорные точки, кожа — мягкая, дополнительные цвета и аккорды
вращаются вместе по цветовому кругу, инструмент объясняет, что делает.

## Что здесь уже есть

- `prototype/` — браузерный прототип «Комплементарный круг»: маркеры на нейтралях, коже, губах, небе и листве,
  нормализация света и кожи, аккорд на круге OkLab, закрепления, история, замеры до/после, экспорт LUT (.cube) и снимка,
  свёртываемые панели и зум. Опубликован как артефакт claude.ai (адрес в `CLAUDE.md`).
- `tools/film_measure/` — конвейер замеров: сколько в разнице плёнок, сканеров и камер приходится на нейтраль, а сколько — на
  «школу цвета». Результаты — `docs/experiments/film_scanner_digital.md`.
- `ITERATIONS.md` — план по итерациям, `ROADMAP.md` — фазы и открытые вопросы, `DECISIONS.md` — что решил Алексей.

## Как запустить

```
python3 prototype/build.py          # собрать; демо-фото — data/demo/demo_portrait.jpg (не в git)
open prototype/build/complement_built.html
```
