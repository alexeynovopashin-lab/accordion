## Итог по воротам (14.10.2026, 22 кадра, 4 плёнки, 2 сканера)
- Серые (светлые, L 81–97): плёнка↔плёнка 2.05 / 4.35 (медиана / p90 ΔE2000) против сканер↔сканер 2.88 / 5.13 — плёнки различаются меньше. Устойчивость: при Ektar 1/30 вместо 1/60 равны.
- Цветные: плёнка↔плёнка 5.32 / 12.47 против сканер↔сканер 5.64 / 10.35 — медианы равны, хвост у плёнок шире. Без яркости 4.23 / 10.34 против 4.05 / 8.04.
- Внутри сканера колебание экспозиции даёт 1–3.5 ΔE на цвете (EV −1…+4) и 0.5–1.6 на серых: яркость нейтралей сканер стирает (L серых 92–96 на всех 7 EV; Noritsu EV −3 — не выравнивает, L 85 и C 8).
- Ошибка разметки (±3 px, окно 0.16–0.30): ≤ 0.1 ΔE по медиане.
- Вывод: абсолютные Lab не читаются как «характер плёнки»; атлас — внутри сканера и по соотношениям. Решение «закрывать ли ворота» — за Алексеем (не спрошено).
