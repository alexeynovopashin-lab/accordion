# Атлас, ступень 1: один кадр «0 EV» на плёнку, Frontier (+ сверка Noritsu)

Измерение, не вывод про школу цвета. Скрипт `tools/film_measure/atlas_ev0.py` (функции разметки скопированы из `gate1.py`,
`gate1.py` и `ratio_transfer.py` не менялись). Таблицы: `data/derived/frontier_ev0_patches.csv` (Lab D50 каждого патча SG,
оба сканера, 24 кадра), `data/derived/frontier_ev0_summary.csv` (сектора). Цвет — CIEDE2000.

## Как выбран кадр «0 EV»
Все доски прочитаны глазами на Frontier (12 страниц × 8 кадров), выбранные кадры сверены на Noritsu (12 из 12 совпали по подписи).
Опора: Portra 400, f/4, 1/125 = EV 0 по заголовку страницы. Свет один, на всех досках f/4 (кроме Portra 160), значит у плёнки
чувствительности N EV 0 — выдержка 1/125 × 400/N.

| Portra 400 | 2, №3 | 1/125 | заголовок |

## Разметка
24 кадра, решётка найдена везде: 102–112 отверстий из 140, шаг 75.2–75.6 px (Frontier), 63.9–64.4 px (Noritsu).
Кросс-процесс (оба сканера) — с порогом чёрного 50 вместо 70. Наложение проверено глазами на 4 кадрах: Frontier Ektachrome,
Frontier кросс-процесс, Frontier Gold, Noritsu Pro Image — рамки в центрах патчей. Портры 160/400, Ektar 1/30, Ultramax пересчитаны
и сверены с `gate1_patches.csv`: расхождение ≤ 0.005 по L, a, b (округление).
Наборы патчей — правило ворот (по Portra 400 EV 0 обоих сканеров): 74 цветных, 29 нейтральных (только светлые, L 81–97).

  По воротам (`gate_iteration1.md`) на EV −1…+4: цвет 1.7–3.5 (Frontier), 1.1–3.8 (Noritsu).
- **Дубль Noritsu стр. 1 №4/№5**: разница 0.0000 — кадры побитно одинаковые, это проверяет только детерминизм разметки, не шум съёмки.
- Других оценок шума нет (повторных кадров одной сцены на одном сканере в данных нет).

Следствие для таблицы: на Frontier Gold, Colorplus, Portra 400 push, Portra 800 (2.3–3.3) отличаются от Portra 400 не больше,
чем Portra 400 от самой себя на ступень экспозиции. Pro Image, Gold push, Portra 160 (3.8–4.3) — на границе. Явно выше шума:
Ektar, Ultramax, Ektachrome, кросс-процесс (5.6–12.2). Поворот оттенка в секторе меньше ~8–13° на Frontier — не отличим от шума.

## Сверка Frontier ↔ Noritsu: сохраняется ли порядок «ближе / дальше от Portra 400»
- Ранговая корреляция Спирмена по 11 плёнкам, цвет: **0.82**; без условных привязок (9 плёнок): 0.78; без двух слайдовых (9 негативов): 0.67.
- По серым: 0.62.
- Порядок грубо сохраняется: «дальние» Ektar, Ultramax, Ektachrome, кросс-процесс — в хвосте на обоих (на Noritsu в хвост
  добавился Gold push). Внутри ближней группы порядок перемешан — там различия в пределах шума.
- В секторах (n ≥ 3) знак поворота и сторона множителя совпали на обоих сканерах в 35 из 66 — около половины.

## Попутно: «у Frontier больше цветов»
Медиана хромы по 74 цветным патчам, 12 плёнок: Frontier **C 44.6**, Noritsu **C 48.3**; попарно Frontier/Noritsu — медиана ×0.94,
Frontier насыщеннее только в 30 % пар. По хроме на мишени слова не подтвердились. Оговорка: «больше цветов» может значить
различимость оттенков, а не насыщенность — это не мерено.

## Оговорки
- Один кадр на плёнку, патчи SG в одном свете (лампа накаливания по заголовкам). Тени и средние серые не размечены.
- Привязка «по ISO» предполагает, что плёнку снимали по паспортной чувствительности; push — по удвоенной.
- Ektar теперь на 1/30, в воротах и `ratio_transfer.md` — на 1/60; числа Ektar между документами напрямую не сравнимы.
- Сектора 120–360° держатся на 4–9 патчах.
