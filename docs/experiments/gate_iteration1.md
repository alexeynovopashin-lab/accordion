# Ворота итерации 1: стирает ли сканер различия между плёнками

Вопрос ворот (`ITERATIONS.md`): если сканер выравнивает кадры так, что различия между плёнками меньше разброса между сканерами,
атлас строится только по соотношениям цветов. Здесь — число для ворот на малой выборке. Скрипт: `tools/film_measure/gate1.py`
(запуск и зависимости — в шапке скрипта), таблицы: `data/derived/gate1_patches.csv` (Lab по патчам), `gate1_summary.csv`.

## Как мерили
- Выборка 22 кадра Charts. Кадр «0 EV» по доске: Portra 400 — 1/125 (EV 0 по Charts), Portra 160 — 1/125, Ultramax — 1/125, Ektar — 1/60
  (на доске нет 1/125; 1/60 и 1/250 равноудалены на ступень, взят 1/60; ISO-эквивалент 1/30 — отдельно, ниже). Серия EV: Portra 400, 7 кадров, оба сканера.
  Подписи на доске прочитаны глазами на Frontier (стр. 1, 7, 10) и сверены на Noritsu (стр. 1 №2, стр. 7 №2 и №3, стр. 10 №3).
- Разметка SG тем же методом, что в прошлых тестах (`sg_lattice.py`, центральные 44% патча, медиана). Порог чёрной рамки пришлось ослабить
  только на одном кадре (Noritsu, Portra 400, EV −3). Найдено 103–112 отверстий из 140 на кадр; шаг 75.2 px (Frontier) и 64.2 px (Noritsu).
  Наложением проверено 3 кадра (Frontier Ektar 1/60, Noritsu Ultramax 1/125, Noritsu Portra 400 EV −3): рамки в центрах патчей.
- Патчи фиксированы по эталонному кадру (Portra 400, EV 0, оба сканера; то же правило, что в `compare_scanners.py`):
  **нейтральные 29 (L 81–97 — только светлые серые), цветные 74** (C>12). Одни и те же позиции на всех кадрах.
- Lab D50 через профиль «Display» → sRGB, CIEDE2000. «С яркостью» = обычный ΔE; «без яркости» = L приравнена. Без нормализации по нейтралям.
- Все ΔE ниже: медиана / 90-й процентиль, n = число патчей (не независимых).

## Вердикт воротам

| Патчи | (в) плёнки | (б) сканеры | (в)/(б) медиана | (в)/(б) p90 |
|---|---|---|---|---|
| серые, с яркостью | 2.05 / 4.35 | 2.88 / 5.13 | 0.71 | 0.85 |
| серые, без яркости | 1.34 / 3.49 | 2.36 / 4.86 | 0.57 | 0.72 |
| цветные, с яркостью | 5.32 / 12.47 | 5.64 / 10.35 | 0.94 | 1.20 |
| цветные, без яркости | 4.23 / 10.34 | 4.05 / 8.04 | 1.04 | 1.29 |

- **Серые: ворота сработали.** Разница между плёнками меньше разброса между сканерами. Оговорка: при Ektar 1/30 вместо 1/60 это превращается в равенство
  (серые (в) 2.90 против (б) 2.88), то есть вывод по серым держится на выборе кадра Ektar и по этой выборке неустойчив.
- **Цветные: плёнки и сканеры одного порядка.** Медианы равны с точностью до 6%, хвост (p90) у плёнок на 20–30% шире. Различие между плёнками
  не превышает разброс сканеров по медиане — по формулировке ворот это «сработало», по хвосту — граница.
- Что переживает выравнивание, по этой выборке: **яркость нейтралей — не переживает** (стёрта сканером, L серых постоянна);
  **цвета «целиком» (абсолютные Lab) как свойство плёнки — не доказаны**: разница от сканера такая же по величине, как разница между плёнками;
  **соотношения** — этим шагом напрямую не проверены. Косвенно: без яркости (в) и (б) тоже равны (4.2 против 4.05), так что одно снятие яркости их не разделяет.
  Внутри одного сканера плёнки различимы: 4.2–5.3 против 1–3.5 от колебания экспозиции (а), то есть в 1.5–4 раза выше шума выравнивания.
- Практический вывод по формулировке ворот: атлас строится **внутри сканера** и по соотношениям; «характер плёнки» нельзя читать из абсолютных Lab.

## Оговорки
- Размер: 4 плёнки, по одному кадру на сканер (Portra 400 — 7), 29 и 74 патча на пару. Пары плёнок делят кадры: 6 пар из 4 кадров на сканер, n патчей не независимы; доверительных интервалов нет.
- Ошибка разметки: рамка сдвинута на ±3 px по осям и по диагонали (±2, ±2), окно 0.16 и 0.30 вместо 0.22. Медианы плывут: серые (б) 2.83–2.91, (в) 2.01–2.10;
  цветные (б) 5.62–5.72, (в) 5.29–5.39; p90 цветных (б) 10.09–10.35, (в) 12.35–12.58. Дрейф ≤ 0.1 ΔE, порядок (в) против (б) от разметки не меняется.
  Не проверено: ошибка самой решётки (поворот, шаг) и пятно/царапины внутри патча.
- Плёнки сняты при одной выдержке на доске, но разном ISO: Ektar 100 при 1/60 переэкспонирован относительно Portra 400 на ~2 ступени, при 1/30 — ровно ISO-эквивалент
  (чувствительность по паспорту, не мерено). Сканер выравнивает, но не весь остаток: экспозиционный вклад в (в) не отделён.
- Серые патчи SG только светлые (L 81–97); тени и средние серые — SpyderCheckr, не размечен.
- Выбор нейтральных и цветных патчей сделан по Noritsu Portra 400 EV 0 (эталонный кадр) — для этого кадра выбор круговой, для остальных нет.
- Нет нормализации по нейтралям и сравнения по секторам круга; Middlebury и остальные 8 плёнок не затронуты.
- EV по доске: Portra 160 и Ektar, Ultramax привязаны не к EV, а к выдержке на доске. Серия Ektar на доске: 1/250, 1/60, 1/30, 1/15, 1/8, 1/4, 1/2 (лампа 1/8);
  Ultramax: 1/1000, 1/250, 1/125, 1/60, 1/30, 1/15, 1/8 (лампа 1/30).
- Данные (кадры) не в git; в git — скрипт, таблицы патчей и сводка.
