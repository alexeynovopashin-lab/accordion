# Переносится ли разница между плёнками между сканерами

Дата 2026-10-14. Только анализ `data/derived/gate1_patches.csv` (22 кадра, 4 плёнки, 2 сканера, 74 цветных патча SG). Скрипт: `tools/film_measure/ratio_transfer.py`
(чистый python, 500 бутстрэп-повторов по патчам, seed 1). Продолжение `gate_iteration1.md`; вывод про ворота не менялся.

## Что считали
- Репер — Portra 400, кадр «0 EV», на каждом сканере свой. `D(F,S) = Lab(F,S) − Lab(Portra 400,S)` по одним и тем же 74 патчам; кадры: Portra 160 и Ultramax 1/125,
  Ektar 1/60 и Ektar 1/30 отдельно. Все 74 патча есть на всех кадрах (решётка из gate1.py дополняет не найденные отверстия).
- «ΔE разности» = ΔE2000 между `ref + D(F,Frontier)` и `ref + D(F,Noritsu)`, ref = среднее Portra 400 двух сканеров. «ab» — без ΔL; «Lab» — с ΔL.
- Нуль: те же числа для `D(F1,Frontier)` против `D(F2,Noritsu)`, F1≠F2, на тех же патчах.
- Корреляция: Δa и Δb вместе (148 точек; 74 патча не независимы — доверие ограничено); в скобках 90%-интервал бутстрэпа.

## Секторы круга (6 × 60° по оттенку Portra 400; n = 22/26/7/9/6/4)
Сдвиг оттенка / множитель насыщенности, Frontier → Noritsu (выборка):
- Portra 160: 0–60° −10→−5°, ×0.93→0.91; 60–120° +16→+4°; 300–360° −23→−11°, ×1.00→0.81.
- Ektar 1/60: 0–60° +3→**−7°**, ×**1.25→0.99**; 180–240° −1→**+13°**; 240–300° ×1.06→**1.27**.
- Ultramax: 0–60° ×**1.18→0.87**; 240–300° +17→+17°, ×1.48→1.45 (единственный сектор, где всё совпало); 300–360° ×1.08→1.28.
Совпало в секторах (из 24 = 4 кадра × 6): знак сдвига оттенка 16/24, насыщенность по ту же сторону от 1 — 15/24, величина оттенка в пределах ×2 — 10/24,
величина насыщенности (log) в пределах ×2 — 8/24; **все четыре условия вместе — 1/24**.
Пороги (×2; «в пределах 1.5° / 3 % — ноль») заданы мной до просмотра результата.

## Вердикт (по критерию задачи)
Критерий: corr Δa,Δb ≥ 0.7 **и** ΔE разности меньше, чем между разностями разных плёнок.
- Portra 160: corr 0.81 ✔, ΔE 2.15 против 3.3–6.8 ✔ — переносится (но это та же семья ISO 160/400, |D| мал).
- Ultramax: corr 0.68 — на 0.02 ниже порога (интервал 0.59–0.77) ✘, на границе.
- Ektar (оба кадра): 0.55–0.57 ✘ — красно-оранжевая насыщенность на Frontier ×1.25, на Noritsu ×0.99.
- **Итог: не переносится** (1 плёнка из 3). Выбор кадра Ektar вывод не меняет (0.57 против 0.55; ΔE 3.5 против 4.1).
- Ошибка переноса (ΔE 2–4 медиана, 8–10 в p90) сопоставима с самой разницей между плёнками внутри сканера (3–8).

## Следствие
- **Атлас по соотношениям — только внутри сканера.** «Ektar даёт +25 % насыщенности в оранжевом» — свойство пары плёнка+сканер, не плёнки.
- Итерация 2 (рецепт): рецепт «школы» привязан к сканеру/лаборатории; межсканерный перенос — отдельная задача (нужна цветовая мишень на каждом кадре), не побочный эффект.
  Разметка 195 кадров имеет смысл внутри одного сканера (Frontier); Noritsu — выборочно для сверки.

## Оговорки
- Один кадр на плёнку и сканер: повторяемость (два кадра одной сцены на одном сканере) не измерена — часть ΔE может быть шумом. Ektar 1/60 и 1/30 — единственная проверка (даёт то же).
- Патчей на сектор 4–26; секторы 240–360° (6 и 4 патча) знаком не вывод.
- Репер (Portra 400) сам различается между сканерами на 5.6 ΔE: разность ловит и разницу тоновых кривых сканеров, не только плёнку. Нейтрали не нормировали.
- Одна мишень (SG), одна сцена, телесных тонов нет; перенос на фотографии не проверен.
