# Плёнка, сканер, цифра: что делает с цветом

Вопрос: какая часть разницы между плёнкой и цифрой, и между двумя сканерами одного негатива, убирается нейтралью (светом), а какая — это «школа цвета».

## Условия
Portra 400, EV 0 (1/125, f/4), набор Charts, лампа накаливания, ColorChecker SG, 140 патчей. Сканы Frontier и Noritsu одного негатива, профиль
Apple Display → sRGB → Lab D50. Сетка патчей: решётка 14×10, повёрнута на −0.7°, шаг 75.2 / 64.2 px, чёрные патчи восстановлены по решётке;
проверено наложением на оба кадра. Цифра: шесть камер Middlebury (Nikon D3, D300, Canon 5D, Fuji S5 Pro, Sony A100, Leica M8),
3200K, wb1, 0 стоп. Данные: `data/derived/`. Метрика: CIEDE2000 (проверена по паре Шарма, 2.0425), цветные патчи C>12, n=74.
«Нормализация по нейтралям» = кривые по каналам, сводящие серые патчи (29 штук, L 78–97) к серой шкале Noritsu.

## Тест 1: Frontier против Noritsu
| Что | Медиана ΔE |
|---|---|
| без обработки | 5.8 (90% патчей до 9.4) |
| после нормализации по нейтралям | 5.1 |
| и яркость выровнена (только цвет) | 4.3 |

После нормализации остаток закономерен: у Frontier менее насыщены красные, жёлтые и зелёные (0.84–0.92 от Noritsu), более — голубые и фиолетовые
(1.11–1.14); оттенки: жёлтый +6°, голубой +7°, фиолетовый −9°, пурпурный −15°. Нейтраль у Frontier в светах теплее (a≈+2), у Noritsu b≈+0.6.

## Тест 2: плёнка против цифры (в тех же условиях нормализации; цвет без яркости)
- RAW-камеры между собой: 3.0 (Leica M8 — выброс, 4–8); JPG между собой 3.9; RAW против JPG одной камеры 4.0.
- Плёнка против цифры: 6.4–6.7. Сканеры между собой: 4.3. Frontier ближе к цифре (5.1–5.7), Noritsu дальше (7.2–8.1).
- Плёнка (Noritsu) против среднего пяти RAW-камер без M8, по семействам: красно-оранжевые C×1.47, +6°; жёлтые ×1.32, −2°; зелёные ×1.27, −10°;
  голубые ×0.71, −25°; фиолетовые ×0.63, −16°; пурпурные ×0.97, +12°.

## Вывод (гипотеза, подтверждается в итерациях 1–2)
Нейтраль убирает меньше пятой части разницы; остаток — зависимость насыщенности и оттенка от места на круге. Её можно записать как карту
по секторам (поворот и множитель насыщенности), то есть «школа» переносима рецептом, а не одной нейтралью.

## Оговорки
- Один кадр, одна плёнка, одна экспозиция.
- RAW Middlebury — сырой отклик без цветовой матрицы; JPG с матрицей дают тот же порядок разницы (6.4), но точные числа от этого зависят.
- Свет разный: у Middlebury 3200K, у Color Precision «tungsten» без температуры. Баланс по серой шкале гасит часть разницы, не всю.
- Серые патчи SG только светлые (L 78–97): поведение нейтрали в тенях не проверено (нужен SpyderCheckr).
- Числа считаны по экрану через профиль «Display», без калибровки к эталону мишени: абсолютные цвета не утверждаются, только разница между системами.
